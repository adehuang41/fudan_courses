\begin{abstract}
本报告围绕 MNIST 手写数字分类，完成了课程项目要求的三个实验模块。Part A 建立了从零实现的 MLP baseline；Part B 在统一训练协议下比较了 MLP 与 CNN；Part C 选择 \texttt{Data Augmentation} 和 \texttt{Robustness Analysis} 两个方向，并将它们组织成一个统一问题：先诊断 \texttt{CNN-clean} 的主要脆弱扰动，再比较 target-only augmentation 与 mixed augmentation，以及 from-scratch training 与 fine-tuning 两条训练路线。结果表明：CNN 在 clean MNIST 上明显优于 MLP，且参数量更少；在 Part C 中，验证集 robustness diagnosis 选出的主要弱点是 \texttt{translation-3}；\texttt{CNN-AugScratch-target} 在 selected target 上最强，而 \texttt{CNN-AugScratch-mixed} 在 target performance 仅小幅回落的前提下取得了更强的 cross-family robustness。相比之下，基于 \texttt{CNN-clean} checkpoint 的 \texttt{CNN-RGFT-target} 与 \texttt{CNN-FT-mixed} 说明 fine-tuning 可以用较低边际成本获得明显鲁棒性提升，但整体上通常仍弱于对应的 from-scratch augmentation baseline。
\end{abstract}

\section{Introduction and Experimental Setup}

本项目按实验流程组织报告。\texttt{MLP baseline}、\texttt{CNN comparison} 和 \texttt{two additional directions} 构成实验主线；\texttt{main results table}、\texttt{detailed visualization} 和 \texttt{discussion} 被整合进对应实验部分，并在最后集中总结。

数据集为标准 MNIST。原始训练集共有 60{,}000 张图像，使用固定随机种子 309 将其划分为 50{,}000 张训练图像和 10{,}000 张验证图像。验证集用于 checkpoint 选择、鲁棒性诊断和 target 选择；官方 10{,}000 张测试集在最终评估之前保持不参与训练和模型选择。除训练随机性之外，鲁棒性评估还固定使用单独的评估随机种子 2026，以保证不同模型之间的 perturbation 采样一致。

所有模型都使用归一化到 $[0,1]$ 的灰度输入。Part A 和 Part B 采用相同的 train/validation split、相同预处理、相同优化器类型和相同 epoch budget；Part C 在此基础上保持同一 clean baseline，再做 target-aware augmentation 或 fine-tuning。主要训练设置见表 \ref{tab:setup}.

关于 \texttt{translation-3} 的实现需要明确说明。训练阶段的 target augmentation 采用 online random translation：对每张图像在横纵两个方向分别随机采样整数位移，范围均为 $[-3, 3]$，超出边界的部分裁剪，新暴露区域用零填充。主线 validation/test 评估中的 \texttt{translation-3} 也沿用这一实现，但使用固定评估随机种子，因此比较是可复现的。为了让 perturbation 定义更直观，后文的 target visualization 还额外展示了四个确定方向的 \texttt{left/right/up/down} 平移示例；这个 deterministic four-direction view 仅用于说明 selected target 的几何含义，而不是主线 Part C 的总体测试指标。

\subsection{From-Scratch Operator Implementation}

MLP 和 CNN 都建立在 NumPy from-scratch computation graph 之上：参数张量由自定义层维护，前向传播显式缓存中间结果，反向传播逐层手写梯度公式，再交给自定义 SGD 更新；整个训练过程没有使用 PyTorch、TensorFlow 或 JAX 的 autograd，也没有调用这些框架内置的卷积、池化或 cross-entropy。

在线性分类链路中，\texttt{Linear.forward} 直接完成 $XW+b$ 的矩阵乘加，\texttt{Linear.backward} 则显式计算对输入、权重和偏置的梯度。损失层使用手写的 multi-class softmax cross-entropy：前向先基于 logits 计算数值稳定的 softmax 概率和平均负对数似然，反向再直接给出 logits 的梯度。总的来说：Part A 的 MLP baseline 是一条 ``Linear $\rightarrow$ ReLU $\rightarrow$ Linear $\rightarrow$ softmax cross-entropy'' 实现链路。

CNN 部分同样依赖自实现算子。\texttt{Conv2D.forward} 先用 \texttt{sliding\_window\_view} 提取局部窗口，再以 im2col-style 的向量化方式完成卷积核与局部感受野之间的批量乘加；\texttt{Conv2D.backward} 显式累积卷积核梯度、偏置梯度，并把梯度散射回输入特征图。这里的 \texttt{sliding\_window\_view} 是 NumPy 的张量重排技巧，用于减少 Python 层循环。池化层 \texttt{MaxPool.forward} 会记录每个窗口的 argmax 位置，\texttt{MaxPool.backward} 只把梯度传回这些最大值位置；\texttt{ReLU} 则在反向阶段按输入符号屏蔽负半轴梯度。

\section{MLP Baseline}

Part A 的目标是建立一个可运行、可解释的 MLP baseline，并验证线性层和 softmax cross-entropy 的前向与反向传播实现正确。模型采用单隐层结构 $784 \rightarrow 256 \rightarrow 10$，激活函数为 ReLU，训练使用 SGD。

这个结果说明 Part A 的基础训练链路已经工作正常，同时为后续 MLP-vs-CNN 比较提供了一个足够强的 clean baseline，而不是一个明显欠拟合的对手。

\subsection{Why the CNN is better suited to image classification}

本实验结果支持以下结构性解释。第一，MLP 在输入层前就把 $28 \times 28$ 图像 flatten 成长度为 784 的向量，显式二维空间邻域被打散。第二，CNN 的 local receptive field 更契合手写数字由局部笔画构成的特点。第三，weight sharing 带来了更高的参数效率，因此相同模式出现在不同位置时不需要重复学习。第四，卷积是 translation-equivariant，而 pooling 和后续空间聚合会提高模型对小范围位移的容忍度。第五，多层卷积可以把低级边缘和笔画段逐步组合成更完整的数字部件。

需要保持表述严谨：普通 CNN 并不会自动获得完美的 translation invariance，更不会天然具有 rotation invariance。事实上，Part C 之所以最终选择 \texttt{translation-3} 作为 target perturbation，正是因为它在验证集上给 \texttt{CNN-clean} 造成了最大的 accuracy drop。这说明 CNN 虽然比 MLP 更适合图像局部模式，但对更强的空间位移仍然存在明确弱点。

\section{Robustness Diagnosis and Augmentation Comparison}

\subsection{Robustness diagnosis and target selection}

Part C 选择了两个 additional directions：
\begin{itemize}
  \item Direction 3: \texttt{Data Augmentation}
  \item Direction 4: \texttt{Robustness Analysis}
\end{itemize}

这两个方向没有被拆成两个彼此独立的小实验，而是被组织成同一个研究问题：先通过 validation robustness diagnosis 找到 \texttt{CNN-clean} 的主要弱点，再围绕该弱点比较两种 target-aware 训练策略。

我先在验证集上评估 \texttt{CNN-clean} 在以下扰动下的表现：
\begin{itemize}
  \item Gaussian noise: $\sigma = 0.05, 0.10, 0.20$

\subsection{Target-only vs Mixed Augmentation under Two Training Routes}

在选定 \texttt{translation-3} 之后，Part C 的主实验被组织成一个清楚的 $2 \times 2$ 比较：一条轴比较 augmentation objective（target-only vs.\ mixed），另一条轴比较 training route（from scratch vs.\ fine-tuning from the \texttt{CNN-clean} checkpoint）。

\paragraph{\texttt{CNN-AugScratch-target}}
从头训练一个新的 CNN，训练时每个 mini-batch 由 50\% clean 样本和 50\% \texttt{translation-3} 样本组成，epoch budget 为 30。这是最直接的 target-only augmentation baseline。

\paragraph{\texttt{CNN-AugScratch-mixed}}
同样从头训练一个新的 CNN，训练配置保持为 30 epochs、batch size 64、SGD、learning rate 0.01。不同之处在于，batch 中 50\% 的 perturbed samples 不再固定为 \texttt{translation-3}；而是在线随机生成，并对每个 perturbed sample 先在 \texttt{noise / translation / rotation} 三个 family 间均匀采样 perturbation type，再在该 family 的 diagnosis grid 内均匀采样 severity，即 $\sigma \in \{0.05, 0.10, 0.20\}$、translation $\in \{1,2,3\}$、rotation $\in \{5^\circ, 10^\circ, 15^\circ\}$。checkpoint selection 也不再只看单一 target，而是使用 validation mixed robustness score：
\[
\text{score} = \text{mean}(\text{clean val acc},\ \text{noise-0.10 val acc},\ \text{translation-2 val acc},\ \text{rotation-10 val acc}).
\]

\paragraph{\texttt{CNN-RGFT-target}}
从 \texttt{CNN-clean} 的 best checkpoint 出发，继续做 diagnosis-guided target repair。训练同样采用 50\% clean 样本和 50\% \texttt{translation-3} 样本，但只追加 10 个 fine-tuning epochs。checkpoint selection 遵循一个显式约束：在 clean validation accuracy 相比 \texttt{CNN-clean} 下降不超过 1 个百分点的前提下，选择 target validation accuracy 最高的 checkpoint。

\paragraph{\texttt{CNN-FT-mixed}}
同样从 \texttt{CNN-clean} 的 best checkpoint 初始化，但 fine-tuning 时不再只围绕 selected target，而是使用与 \texttt{CNN-AugScratch-mixed} 相同的 mixed perturbation distribution：50\% clean 样本加 50\% mixed perturbed 样本，并在 \texttt{noise / translation / rotation} 三个 family 之间随机采样。

图 \ref{fig:partc_grouped_bar} 把这个 $2 \times 2$ 比较可视化为三项指标：Clean Test、Target Test 和 Robust Avg。它把 Part C 的 trade-off 展示得更直接：target-only 方法在 selected target 上最好，而 mixed 方法在整体 robustness 上更均衡；同时，from-scratch 仍然是更强的训练路线，fine-tuning 的主要优势在于 marginal cost 更低。

这组三族曲线支持三个直接判断。第一，\texttt{CNN-clean} 在 \texttt{translation-3} 上下降最明显，与前面的 target selection 完全一致。第二，target-only 方法主要改善 translation curve；其中 \texttt{CNN-AugScratch-target} 在 \texttt{translation-3} 上达到 0.9568，是所有模型中最高的。第三，mixed 方法在 noise、translation 和 rotation 三个 family 上都更均衡，特别是 \texttt{CNN-AugScratch-mixed} 的整体曲线最平稳，因此它更适合作为 broad robustness 的 baseline。相比之下，\texttt{CNN-FT-mixed} 也获得了明显的 cross-family 提升，但仍未超过从头训练的 mixed baseline。

从 family-level 的角度看，这些曲线还有三点值得单独强调。对 \texttt{noise} 而言，\texttt{CNN-clean} 本身对轻中度 Gaussian noise 已经比较稳定，但 mixed augmentation 对强 noise 更有帮助，因此 \texttt{CNN-AugScratch-mixed} 与 \texttt{CNN-FT-mixed} 在 \texttt{noise-0.20} 上都明显优于 target-only 路线。对 \texttt{translation} 而言，\texttt{CNN-clean} 在 \texttt{translation-3} 上下降最大，而 target-only repair 对整条 translation curve 的提升最明显，这正是 diagnosis-guided target repair 的核心收益。对 \texttt{rotation} 而言，整体掉点小于 translation，但 mixed augmentation 在三个 rotation severity 上都更均衡，因此如果目标是 broad robustness，rotation family 的收益主要来自 mixed training distribution，而不是只修 selected target。

\section{Conclusion}

整个项目可以概括为三层递进。首先，Part A 证明了从零实现的 MLP 训练链路是正确的。其次，Part B 表明 CNN 在 clean MNIST 上以更少参数取得了更好的验证与测试性能，说明卷积结构比全连接结构更契合图像任务。最后，Part C 通过 robustness diagnosis 找到了 \texttt{CNN-clean} 的主要 weakness \texttt{translation-3}，并据此组织 target-only augmentation 与 mixed augmentation、from-scratch training 与 fine-tuning 的 $2 \times 2$ 主实验。结果表明：\texttt{CNN-AugScratch-target} 对 selected target 的修复最强；\texttt{CNN-AugScratch-mixed} 在牺牲很少 target performance 的前提下取得了更强的 broad cross-family robustness；而 \texttt{CNN-RGFT-target} 与 \texttt{CNN-FT-mixed} 则说明，基于 \texttt{CNN-clean} checkpoint 的 fine-tuning 可以提供一条较低边际成本的鲁棒性修复路线，但从头增强训练仍然是更强的 baseline。同时，targeted 的两种方法也有局限：它们能有效修复被诊断出的 \texttt{translation-3} weakness，但由于训练目标集中在单一 selected target 上，对其他 perturbation family 的提升并不一定均衡。若目标是获得更广泛的 cross-family robustness，而不只是修复一个已知弱点，训练分布仍然需要覆盖 noise、translation 和 rotation 等多类扰动。因此，targeted repair 更适合低成本、定向修复；mixed augmentation 则更适合追求整体稳定性。
